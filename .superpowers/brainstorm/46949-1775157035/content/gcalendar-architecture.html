Strategy: Direct GCalendar Sync

  • Data Source: Uses the Google Calendar REST API to fetch today's events for the authenticated user.
  • Security: Leverages the existing OAuth2 flow and secure Keychain storage for the calendar.readonly scope.
  • Intelligence: The GCalendarService parses event descriptions and locations to find "Meeting Notes" URLs (Docs) and pre-fills templates using participant data.
  • Sidebar Integration: Today's meetings appear in the collapsible sidebar, just as planned, but are sourced directly from Google.
