Strategy: Intelligent Meeting Templates

  • Keyword Detection: If the title contains "1:1", "Sync", or "Interview", the engine automatically selects the corresponding Markdown template.
  • Participant Mapping: Attendees are converted into @mention chips at the top of the note. If a manager is detected, a specialized "1:1 with Manager" template is used.
  • Doc Linkage: If a Google Doc URL is found in the event, updoc automatically links the note and pulls in existing content.
  • "Apply My Template" Action: For empty foreign docs, a button in the header allows the user to push their selected template into the document.
  • Persistence: Selected templates are stored locally in SwiftData, allowing for offline note preparation.
