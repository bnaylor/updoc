Core Sync Components

  • Sync Coordinator: The central Swift Actor that manages the "Live-ish Sync" process, ensuring that local edits are pushed and remote changes are pulled asynchronously.
  • OAuth2 Manager: Handles the initial authentication flow via system browser redirect and stores tokens securely in the macOS Keychain.
  • Drive API Monitor: Periodically checks the "Head" version of the linked Google Drive files to detect external changes.
  • Docs API Synchronizer: Performs the actual content sync, including converting local Markdown to Google Docs JSON structure and back.
