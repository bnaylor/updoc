Strategy: OAuth2 & Security Architecture

  • System Browser Redirect: We'll use the industry-standard OAuth2 redirect flow via the system browser (Chrome/Safari) to ensure a secure login experience.
  • Keychain Storage: All sensitive credentials (access tokens, refresh tokens, client secrets) are stored in the macOS Keychain, protected by system-level security.
  • Principle of Least Privilege: We'll request only the necessary scopes for Google Docs and Drive access, ensuring we don't overreach.
  • Secure SwiftData: Local note content is stored in SwiftData. We'll leverage macOS system encryption for the data folder to protect user data.
