Background Sync Strategy

Decide how updoc handles background sync for your notes.

1

Foreground Only

Only sync the note you're currently editing. Minimal battery/data usage.

2

Intelligent Pre-fetch

Sync the current note + any notes for upcoming meetings (linked via calendar).

3

Full Background Sync

Periodically sync ALL notes. Ensures everything is always up-to-date and searchable.

Consider the trade-off between battery/resource usage and having everything always "ready to go". Which approach fits your vision?
