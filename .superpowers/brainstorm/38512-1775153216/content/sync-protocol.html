Strategy: Bidirectional Merge Protocol

  • Sync Cycle: Every 2 seconds of inactivity, updoc triggers a "push" for local changes. Periodically (e.g., every 30 seconds), it triggers a "pull" to check the Drive "Head" version for external changes.
  • Change Detection: We'll maintain a `lastSyncedRevision` for each linked Google Doc. If the remote revision is greater, we fetch the remote content.
  • Auto-Merge Logic: We'll use a standard 3-way merge algorithm (Base vs Local vs Remote). Non-overlapping line changes are merged automatically.
  • Conflict Resolver UI: For overlapping changes, the side-by-side resolver (from the earlier mockup) is presented, allowing you to choose which version to keep.
  • Version History: By pushing changes in small batches, we leverage Google Docs' native version history for safety and traceability.
