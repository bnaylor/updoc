Key Features

  • TextKit 2 Editor: A native macOS text view optimized for performance. It will handle the transformation of Markdown syntax into visually styled text in real-time.
  • Intelligent Chips: Typing @ will trigger a Moma directory lookup, embedding a "Contact Chip" similar to Google Docs. We'll also support dropdown chips for status tracking.
  • Image Support: Drag & drop or paste images directly into the editor. Images are stored locally and synced to the linked Google Doc.
  • Native Interaction: Full support for macOS system features (spelling, grammar, dictation, services).
