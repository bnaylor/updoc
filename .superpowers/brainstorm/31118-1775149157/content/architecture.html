Core Components

  • UI Layer: Uses SwiftUI for a modern, responsive interface. The editor uses TextKit 2 for high-performance text rendering and "Live-Preview" Markdown behavior.
  • Sync Coordinator: A dedicated Swift Actor that manages the "Live-ish Sync" with Google Docs, ensuring local edits are pushed and remote changes are pulled without blocking the UI.
  • Markdown Engine: Responsible for parsing Markdown into styled text for the editor and converting it back for storage and GDocs export.
  • Data Layer: Uses SwiftData for local persistence, ensuring offline access and fast search.
