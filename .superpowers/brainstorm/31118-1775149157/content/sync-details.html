Strategy: "Live-ish" Sync Coordinator

  • Intermediate Representation (AST): We'll parse Markdown into a JSON-based Abstract Syntax Tree (AST). This allows us to map Markdown elements (headings, lists) and custom "Chips" to the exact structures required by the Google Docs API.
  • Debounced Updates: To avoid rate limiting and ensure "no lag," local changes will be debounced before being pushed to Google Docs in batch requests.
  • Version Management: We'll use the Drive API's "Head" version to detect external changes. When an external change is detected, we'll perform a non-destructive merge into the local Markdown.
  • Offline Resilience: Edits made offline are stored in SwiftData. Upon reconnecting, the Sync Coordinator will replay these changes to the linked Google Doc.
